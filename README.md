# java-racingcar-precourse

## 🛠️ 구현할 기능 목록

### 📥 입력

- 경주할 자동차 이름을 입력받는다. 이때, 이름은 쉼표를 기준으로 분류한다.
- 시도할 횟수를 입력한다.

---

### 🚗 경주

- 각 자동차 마다 무작위 값을 추출한다.
    - 4 이상일 경우, 전진한다.
    - 이 과정을 사용자가 입력한 시도할 횟수 만큼 반복한다.
- 가장 많이 전진한 자동차가 1대 이상일 경우 모두 우승자이다.

---

### 📤 출력

- 게임이 끝난 후, 차수별 실행결과를 자동차 이름과 함께 출력한다.

    ```
    pobi : --
    woni : ----
    jun : ---
    ```

- 게임이 끝난 후, 최종 우승자를 출력한다.
    - 우승자가 1명 이상이면 쉼표로 구분해서 출력한다

    ```
    최종 우승자 : pobi, jun
    ```

---

### ‼️ 예외

- 자동차 이름 입력 값에 쉼표 이외의 문자가 있을 경우 예외를 발생한다. → `IllegalArgumentException`
- 자동차 이름이 5자를 초과한다면 예외를 발생한다. -> `IllegalArgumentException`
- 자동차 이름 중 중복 값이 있다면 예외를 발생한다 -> `IllegalArgumentException`
- 시도할 횟수에 음이 아닌 정수 외의 값이 입력될 경우 예외를 발생한다. → `IllegalArgumentException`
